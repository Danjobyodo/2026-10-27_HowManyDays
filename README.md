# 何日間？ - 日数計算 PWA

2つの日付（年月日）を入力して「計算する」を押すと、その間が何日離れているかを表示する Web アプリです。

- `2026-10-26 → 2026-10-27` は **1日**、同じ日は **0日**、終了日が前なら **-1日** のようにマイナスで表示
- 日付を入力すると横に曜日を自動表示（土曜は青、日曜は赤）
- 閏年（4で割り切れる年。ただし100で割り切れる年は除き、400で割り切れる年は含む）を考慮
- JavaScript の `Date` は使わず整数演算で計算するため、タイムゾーンや夏時間、0〜99年の解釈ズレの影響を受けません（0001〜9999年に対応）
- 補足として週数換算・両端を含めた日数も表示
- PWA 対応（ホーム画面に追加可能、Service Worker によりオフラインでも動作）

## GitHub Pages で公開する

ビルド不要の静的ファイルのみで構成されています。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、公開したいブランチと `/ (root)` を選んで保存

パスはすべて相対パスなので、`https://<user>.github.io/<repo>/` のようなサブパスでもそのまま動作します。

## ファイル構成

| パス | 内容 |
| --- | --- |
| `index.html` | 画面 |
| `css/style.css` | スタイル（ダークモード対応） |
| `js/date-utils.js` | 日付計算ロジック |
| `js/app.js` | 画面の動作・Service Worker 登録 |
| `sw.js` | Service Worker（オフライン用キャッシュ） |
| `manifest.webmanifest`, `icons/` | PWA 用マニフェストとアイコン |
| `tests/` | 計算ロジックのテスト |

ファイルを更新したときは `sw.js` の `CACHE_VERSION` を上げてください（キャッシュが入れ替わります）。

## テスト

```sh
node --test tests/*.test.js
```

0001〜9999年の全月について、`Date` による計算結果と一致することも確認しています。
